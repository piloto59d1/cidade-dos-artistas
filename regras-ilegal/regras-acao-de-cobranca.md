# Regras Ação de Cobrança

{% stepper %}
{% step %}

## História prévia

Toda ação de cobrança deve ter uma história construída anteriormente.
{% endstep %}

{% step %}

## Cobrar a pessoa certa

Você deve ter certeza de que está cobrando a pessoa certa, caso contrário poderá ser punido.
{% endstep %}

{% step %}

## Gravações obrigatórias

Deve haver a gravação da ação que gerou a cobrança, bem como gravação da cobrança para comprovar em denúncias caso seja necessário.
{% endstep %}

{% step %}

## Anúncio ao jogador

A ação de cobrança não precisa ser anunciada pela prefeitura, mas deve ser anunciada ao jogador que será cobrado, a exemplo: Sua morte será uma cobrança pelo que aconteceu no momento passado.
{% endstep %}

{% step %}

## Prazo para a cobrança

A ação de cobrança deverá acontecer em um prazo de até 12 horas do acontecido. Qualquer cobrança feita num prazo maior estará sujeito a punição.
{% endstep %}

{% step %}

## Casos particulares e situacionais

Em casos particulares e situacionais, onde já ultrapassou o tempo limite para o **RP** ser gerado, o jogador deve se conduzir até a prefeitura para que tenha autorização de um **STAFF**que exerce a função de **ADMINISTRADOR**, assim, podendo gerar o **RP** dependendo da decisão do **STAFF**.
{% endstep %}
{% endstepper %}
