# Ammunation

* Se for negociada fuga limpa, a polícia deve colaborar. **(Necessário refém)**
* São permitidos apenas 2 veículos para fuga.
* Permitido 1 policial a mais do que os bandidos, seguindo a regra de mínimo e máximo.
* Proibido realizar a ação sem arma.
* Negociação somente será válida com refém.

{% hint style="danger" %}
**FICA PROIBIDO REVISTAR ANTES DO ENCERRAMENTO DA AÇÃO, QUALQUER QUEBRA DE REGRA SUJEITO À ADVERTÊNCIA**
{% endhint %}

### Especificação

| Descrição               | Informação                                                                        |
| ----------------------- | --------------------------------------------------------------------------------- |
| Horário                 | Livre **(Fica proibido puxar faltando 1h para o RR)**                             |
| Fuga                    | Permitido                                                                         |
| Armamento               | Pistola **(Proibido Glock Rajada)**                                               |
| Bandidos                | Mínimo: 2 \| Máximo: 4                                                            |
| Policiais               | Mínimo: 2 \| Máximo: 5 **(Somente 1 Policial a mais do contigente dos Bandidos)** |
| Reféns                  | Mínimo: 0 \| Máximo: 1                                                            |
| Negociação              | Sim                                                                               |
| Valor Máximo por Refém  | 70K **(Sujo)**                                                                    |
| Loot de Policiais       | Não Permitido                                                                     |
| Uso de Capacete         | Não Permitido                                                                     |
| Uso de Drone            | Não Permitido                                                                     |
| Uso de Gás Lacrimogêneo | Não Permitido                                                                     |
| Uso de Helicóptero      | Somente Policial                                                                  |
| Uso de Escudo           | Não Permitido                                                                     |

{% hint style="danger" %}
**Qualquer quebra de regra, será considerado AntiRP.**
