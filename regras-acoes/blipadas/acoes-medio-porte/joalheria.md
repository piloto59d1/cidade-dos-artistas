# Joalheria

* Essa ação obrigatoriamente tem que ser iniciada após as 18h00 ( nárnia ) e encerrar até as 01h00 ( nárnia )
* Fuga não é permitida, ação apenas para troca de tiro.
* Proibido realizar a ação sem arma
* Negociação somente será valido com refém

{% hint style="danger" %}
**FICA PROIBIDO REVISTAR ANTES DO ENCERRAMENTO DA AÇÃO, QUALQUER QUEBRA DE REGRA SUJEITO À ADVERTÊNCIA**
{% endhint %}

### ESPECIFICAÇÃO

| DESCRIÇÃO               |                                                                                       |
| ----------------------- | ------------------------------------------------------------------------------------- |
| Horário                 | Inicio: 18h00 \| Término: 01h00                                                       |
| Fuga                    | Proibido                                                                              |
| Armamento               | Somente **FUZIL** e **SUB** ( PROIBIDO USO DA DOZE DE BORRACHA )                      |
| Bandidos                | Mínimo: 4 \| Máximo: 8 **( Obrigatório 3 Fora )**                                     |
| Policiais               | Mínimo: 6 \| Máximo: 10 **( Somente 2 Policiais a mais do contigente dos Bandidos )** |
| Reféns                  | Sem limite                                                                            |
| Negociação              | Sim                                                                                   |
| Valor Máximo por Refém  | 70K **( Sujo )**                                                                      |
| Loot de Policiais       | Não Permitido                                                                         |
| Uso de Capacete         | Não Permitido                                                                         |
| Uso de Drone            | Negociável                                                                            |
| Uso de Gás Lacrimogêneo | Negociável                                                                            |
| Uso de Helicóptero      | Somente Policia **( Negociável )**                                                    |
| Uso de Escudo           | Negociável                                                                            |
| Uso de Doze ou Sniper   | Negociável                                                                            |
