# Carro Forte

1. Não existe limite de jogadores para nenhum lado, desde que os atuantes no lado ilegal estejam todos envolvidos na ação no começo da ação.
2. Não é permitido dirigir o carro forte.
3. Os policiais só poderão utilizar força letal para cessar uma injusta agressão, a exemplo: chegar e ver os assaltantes com armas em punho, ou até mesmo caso sejam recebidos a tiros.

| Descrição         | Valor                                                  |
| ----------------- | ------------------------------------------------------ |
| Horário           | Sem horário definido                                   |
| Fuga              | A ação deve acontecer e permanecer no norte da cidade. |
| Armamento         | Não existe limitação de armamento nesta ação.          |
| 💀 Bandidos       | Mínimo 4 \| Máximo: Ilimitado                          |
| 🚨 Policiais      | Ilimitado                                              |
| Reféns            | Não permitido                                          |
| Loot de Policiais | Não permitido                                          |
