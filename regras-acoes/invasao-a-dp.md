# Invasão a DP

{% stepper %}
{% step %}

## Participação

Só é permitida a participação de uma comunidade e uma comunidade aliada.
{% endstep %}

{% step %}

## Agendamento

A ação precisa ser marcada com 24h de antecedência, combinando data e hora exatas. Deve ser agendada com a prefeitura.
{% endstep %}

{% step %}

## Reféns

Não é negociável e não é permitido o uso de reféns.
{% endstep %}

{% step %}

## Helicópteros

Polícia e bandidos podem usar helicóptero nesta ação.
{% endstep %}

{% step %}

## Vitória dos bandidos

Em caso de vitória dos bandidos, a queima de arquivos é obrigatória, e a polícia perderá todo o material de investigação sobre a facção envolvida.
{% endstep %}
{% endstepper %}

💀 **Bandidos:** mínimo 12 | máximo 35

🚨 **Policiais:** mais 5 em relação aos bandidos
