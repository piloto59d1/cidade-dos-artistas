# Comboio Exercito Brasileiro

## EXÉRCITO:

{% stepper %}
{% step %}

### Ação do comboio

A ação do comboio **DEVE** ser notificada à prefeitura quando agendada.
{% endstep %}

{% step %}

### Participação de corporações

Só é permitida a participação de duas corporações na ação, sendo 15 (QUINZE) membros do Exército e 15 (QUINZE) da corporação que solicitar a limpeza.
{% endstep %}

{% step %}

### Apoio

É proibido chamar apoio.
{% endstep %}

{% step %}

### Retorno à ação

É proibido morrer e voltar para a ação.
{% endstep %}

{% step %}

### Apoio de outras corporações

É proibido outras corporações vierem para apoiar mesmo aparecendo as notificações de disparos.
{% endstep %}

{% step %}

### Óbito constatado

Mortos por tiro é óbito constatado, ou seja, bandidos e policiais não podem ser reanimados.
{% endstep %}

{% step %}

### Armamentos

Permitido todos os tipos de armamentos (ARMAS).
{% endstep %}

{% step %}

### Blindados

Só é permitido 2 (DOIS) blindado no comboio, sendo 1 (UM) blindado do Exército Brasileiro e 1 (UM) da corporação que solicitou a limpeza de baú.

Caso a unidade solicitante da limpeza de baú não possua veículo blindado disponível, o Exército poderá realizar o deslocamento e a operação utilizando dois veículos blindados próprios.
{% endstep %}

{% step %}

### Helicópteros, blindados e veículos com mísseis

É proibido helicóptero,Blindados ou outros veiculos com misseis teleguiados (somente helicópteros com atiradores e blindados com .50 são permitidos).
{% endstep %}

{% step %}

### Registro dos materiais

Ao início da movimentação dos materiais apreendidos para o 5TON (carreta), é **OBRIGATÓRIO** realizar um registro de PRINT OU VÍDEO dos materiais que forem transportados (poderá ser solicitado pela prefeitura).
{% endstep %}

{% step %}

### Entrada e saída

É obrigatorio a entrada pela Alpha e a saida pela bravo
{% endstep %}
{% endstepper %}

### FACÇÕES:

{% stepper %}
{% step %}

### Loot de policiais

É permitido lootear policiais, inclusive durante a ação.
{% endstep %}

{% step %}

### Óbito constatado

Mortos por tiro é óbito constatado, ou seja, bandidos e policiais não podem ser reanimados.
{% endstep %}

{% step %}

### Armamentos

Permitido todos os tipos de armamentos (ARMAS).
{% endstep %}

{% step %}

### Retorno à ação

É proibido morrer e voltar para a ação.
{% endstep %}

{% step %}

### Apoio

É proibido chamar apoio.
{% endstep %}

{% step %}

### Blindados e helicópteros

Só é permitido o uso de no máximo 3 (TRÊS) blindados e 3 (TRÊS) helicópteros.
{% endstep %}

{% step %}

### Materiais quebrados

Após a carga ser roubada e se houver materiais quebrados, então é permitido a negociação com a prefeitura para renovação dos materiais quebrados.
{% endstep %}

{% step %}

### Membros do ilegal

São permitido no máximo 35 (TRINTA E CINCO) membros do ilegal nessa ação, podendo ser de facções diferentes, regra ÚNICA e EXCLUSIVA ao comboio.
{% endstep %}
{% endstepper %}
