# Abordagens Policiais

### Em casos de abordagens, poderá seguir abaixo:

{% stepper %}
{% step %}

## Iniciar um RP com a polícia!

Respeitando sempre o bom senso, ouça a voz do policial e acate as ordens emandas.

{% hint style="warning" %}
**RENDER-SE:** Ao levantar as mãos durante um assalto ou abordagem policial, o jogador não poderá mais reagir. Em abordagens policiais, é permitido tentar fugir **a pé**, porém reagir após a rendição será considerado quebra de regra.
{% endhint %}
{% endstep %}

{% step %}

## Iniciar fuga!

Neste caso, o jogador deverá manter a fuga limpa. Caso corra para alguma área de risco e disparem contra os policiais, poderá ser considerado cop bait e será passível de punição a facção.

{% hint style="warning" %}
**FUGA OBRIGATÓRIA:** Caso a polícia inicie uma perseguição, o criminoso deve fugir ativamente. Ficar parado ou tomar qualquer outra ação que leve a uma confrontação direta com os policiais será considerado um agravante.
{% endhint %}
{% endstep %}
{% endstepper %}
