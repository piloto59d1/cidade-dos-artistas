# Safezones

### Regras Safezones

* É proibido cometer qualquer crime (roubo, furto, sequestro, atirar, ameaçar, matar, entre outros)
* É proibido ficar trocando socos, seja entre amigos ou não, como brincadeira ou não.
* É proibido ficar chutando/socando veículos estacionados.
* É proibido qualquer tipo de baderna, empinando moto, cantando pneu ou qualquer coisa relacionada.
* É proibido roubos/furtos de veículos ou pessoas.
* Caso a ação se inicie fora das áreas informadas aqui e o jogador leve para dentro de qualquer uma dessas áreas, a ação pode continuar, utilizando o bom senso.
* É proibido cometer qualquer crime (roubo, furto, sequestro, atirar, ameaçar, matar, entre outros) dentro das seguintes áreas
